# Project Overview

Vic Modern Hotel contains three floors and eight departments. Each floor uses one switch and one router. Department traffic is segmented with VLANs and routed using router-on-a-stick. The routers form a triangle of serial point-to-point links and exchange routes with OSPF Area 0.

## Skills demonstrated

- IPv4 addressing and subnetting
- VLAN segmentation
- 802.1Q trunking
- Router-on-a-stick
- OSPF
- DHCP
- SSH
- Switch port security
- Cisco IOS verification/troubleshooting
- Evidence-driven technical documentation
