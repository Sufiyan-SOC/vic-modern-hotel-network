# VLAN Configuration

Each department has a dedicated VLAN.

- F1: VLAN 80 Reception, 70 Store, 60 Logistics
- F2: VLAN 50 Finance, 40 HR, 30 Sales/Marketing
- F3: VLAN 20 Admin, 10 IT

`show vlan brief` supplied for all switches confirms the access-port assignments. `Fa0/1` is configured as the trunk on each floor switch.
