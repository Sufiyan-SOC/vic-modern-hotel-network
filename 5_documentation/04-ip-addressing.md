# IP Addressing

Department networks follow the supplied addressing plan from `192.168.1.0/24` through `192.168.8.0/24`, with each department mapped to its specified VLAN.

Router subinterfaces provide the `.1` gateway for each subnet.

See [`../addressing/vlan-table.md`](../addressing/vlan-table.md) and [`../addressing/ip-addressing-table.md`](../addressing/ip-addressing-table.md).
